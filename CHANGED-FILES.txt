এই zip-এ origin/main-এর তুলনায় বদলানো সব ফাইল আছে (১৩টি)। রিপোর কাঠামো ঠিক
রেখে উপরে কপি করে দিন — একই নামের ফাইল replace হবে — তারপর commit করে push
করুন। কোনো ফাইল মুছতে হবে না।

★★ Upload দ্রুত করা (এবারের মূল কাজ)
  প্রতিটা chunk-এর আকার এখন আগের chunk কত দ্রুত গেল তা দেখে ঠিক হয় —
  ধীর নেটে ছোট (drop হলে কম লস), দ্রুত নেটে বড় (কম round-trip)। পরের
  chunk আগেই ডিস্ক থেকে পড়ে রেডি রাখে। ৩০MB ফাইলে request প্রায় অর্ধেক
  (৪ → ২)। একসাথে কয়টা ফাইল যাবে সেটাও env দিয়ে বদলানো যায় (default ২)।
    services/config.js, public/js/upload-engine.js, routes/api.js,
    public/js/tour.js, public/js/admin.js, .env.example

★ আগের turn-এর ৪টা ফিচারও এই zip-এ (origin-এ এখনো যায়নি):
  📸 আমার ছবি খুঁজুন, ↗ শেয়ার, ♥ রিঅ্যাকশন, ▶ স্লাইডশো
    routes/api.js, middleware/rateLimiters.js, public/gallery.html,
    public/js/gallery.js, public/css/app.css,
    test/22-find-me.test.js, test/23-find-me-off.test.js

নতুন env (সব ঐচ্ছিক, .env.example-এ আছে):
  UPLOAD_CHUNK_MB=24   (server ceiling; আগে ৮ ছিল)
  UPLOAD_CHUNK_MIN_MB / MAX_MB / START_MB   (adaptive window)
  UPLOAD_CONCURRENCY=2  (একসাথে কয়টা ফাইল)

কপি করার পর:
  npm test        → ৪৬টি পাস হওয়ার কথা
  npm run check

git am /path/to/patch দিয়ে লাগানোই পরিষ্কার।
